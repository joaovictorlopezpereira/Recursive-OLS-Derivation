## Description

This repository contains the source code for the slides presented at SIAc 2026, held at the Federal University of Rio de Janeiro (UFRJ). The presentation was titled *"Equational Reasoning for the Derivation of Linear Algebra Algorithms from an Optimization Perspective"*.


## References

Trefethen, L. N., & Bau, D. (2022). *Numerical Linear Algebra*. Society for Industrial and Applied Mathematics.

Bùi, H. T., Bùi, M. N., & Clason, C. (2025). *Convex Analysis in Spectral Decomposition Systems*. arXiv preprint arXiv:2503.14981.
